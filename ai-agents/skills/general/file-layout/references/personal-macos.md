# Personal macOS profile

```text
~/
├── projects/
│   ├── code/          # Side-project repositories
│   └── personal/      # Non-code outcome-driven projects
├── learning/          # Courses, exercises, study notes
├── documents/
│   ├── finance/
│   ├── health/
│   ├── travel/
│   └── household/
├── media/
│   ├── videos/
│   ├── photos/
│   └── screenshots/
├── reference/         # Reusable resources not owned by a project
├── scratch/           # Temporary experiments
├── archive/           # Inactive material, optionally by year
├── Downloads/         # Inbox
└── Desktop/           # Inbox
```

Candidate locations, not folders to create up front.

## Placement

- Ongoing study goes in `~/learning/`; move it to `~/projects/code/` once it becomes a real software project.
- Personal records go in `~/documents/`, with encryption, access controls, and backups matched to their sensitivity.
- Keep entertainment media apart from code and records. A large library may belong on an external volume, such as `/Volumes/Media/Movies/` and `/Volumes/Media/TV/`.
