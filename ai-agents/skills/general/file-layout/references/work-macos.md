# Work macOS profile

```text
~/
├── work/
│   ├── repos/         # Company source repositories
│   ├── projects/      # Non-code initiatives and deliverables
│   ├── notes/         # Work notes not tied to one project
│   └── scratch/       # Disposable analysis, never durable output
├── personal/          # Only if policy permits personal material
│   ├── projects/      # Non-code personal projects
│   ├── code/          # Personal repositories
│   └── documents/     # Non-sensitive personal documents
├── Downloads/         # Inbox
├── Desktop/           # Inbox
└── archive/
    ├── work/
    └── personal/
```

Candidate locations, not folders to create up front.

## Placement

- Project documents go with their project, or in `~/work/projects/` when the project has no folder.
- Keep sensitive personal records off a managed laptop; device administrators may have access.
- Keep company and personal Git identities, remotes, and credentials separate.
- Sync company information only to company-approved services.
